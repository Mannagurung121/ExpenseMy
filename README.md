
# ExpenseMy 💸

AI-powered iOS expense tracker built using SwiftUI + SwiftData.

ExpenseMy automatically parses bank SMS messages using NLP-based text processing and converts them into categorized transactions with analytics, charts, widgets, and share extension support.

---

## Features 

- 📩 NLP-based SMS parsing
- 💳 Automatic expense tracking
- 📊 Beautiful analytics dashboard
- 🍩 Category-wise spend charts
- 📅 Monthly expense visualization
- 🧠 Smart transaction categorization
- 📱 iOS Widgets support
- 🔗 Share Extension support
- ⚡ SwiftUI + SwiftData architecture
- 🎨 Modern custom UI

---

## Tech Stack 🛠

- SwiftUI
- SwiftData
- WidgetKit
- Charts Framework
- NLP / Regex-based SMS parsing
- Share Extensions
- App Groups

---

## How It Works ⚙️

1. Share a bank SMS to ExpenseMy
2. App extracts transaction data
3. NLP parser identifies:
   - amount
   - merchant
   - bank
   - debit/credit type
4. Transaction gets categorized automatically
5. Dashboard updates analytics & charts instantly
